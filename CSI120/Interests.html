Fighting Games and why they are neat

Hello my name is Carlos and I am so enthusiastic to tell you about
fighting games! I grew up playing fighting games since I was around five
years old. They have been a fun hobby ever since.

Why fighting games?

Here are five reasons why I find fighting games to be interesting:

  1. Quite similar to playing speed chess in terms of number of actions
    needed while also being 1 on 1 making gameplay quite personal because no opponent plays the same.
  2. There is an element of rock, paper, scissors which leads to mind games
  3. There is a competitive element to fighting games that makes it fun
  4. Execution when performing combos can be both fun and callenging
  5. Sharing what you learned with others

How are fighting games like Rock, Paper, Scissors?

  • Attacking = Rock
    Attacking > Throwing
  • Blocking = Paper
    Blocking > Attacking
  • Throwing = Scissors
    Throwing > Blocking

What is execution in fighting games?

Execution are the type of commands that a fighting game asks from you to perform special moves.
The range of commands is vast and no imput is made the same, this challege that the game demands from you
when creating a complex combination of attacks is where part of the fun comes from next to how fighting games
are a personal match between two players.

How does someone share what they learned to others?

Sharing information surrounding combos in fighting games was interesting back when forums
were common and video sharing was a bit rare in the 90s. The community found a way to share
information on combos with the help of "Number Pad" notation. Inspired by the layout that you would
see on a calculator or number pad on a keyboard it happens to resemble the square shape that an arcade joystick
would feel like thanks to the square gate installed in the cabinet. The number 5 on a number pad would be the
arcade joystick in a neutral position with 8 bring up, 2 down, 4 left, and 6 right. When a user wanted to describe
a motion to another user they would combine the numbers together in the order the stick had to move, such as a Quarter
Circle Forward Motion being "236" which would mean the user had to move their arcade stick down(2), down-forward(3), and
forward(6) in that order if their character was on the left side of the screen facing their opponent that is on the right.
If the user's character were to be swapped and was now on the right side of the screen, the motion would have to reflect that,
meaning a Quarter Circle Forward would now be "214".

Quarter Circle Forward Motion (QCF): 236
Quarter Circle Backwards Motion (QCB): 214
Dragon Punch (or Z Motion) Motion: 623
Half Circle Forward: 41236
Half Circle Backwards: 63214

Now what I just described is only what the left hand of a player would be operating, there is still
the right ride of the controls the user would operate which would be the button layout. Button
layouts vary in any fighting game ranging from 6 buttons to 3 buttons. For the example I will be
using later we will be using a 4 button layout, but the question is which layout would that be?
In fighting games there are two kinds of layouts a 4 button fighter can have, Line Layout with all
four buttons next to each other allowing the user to rest a finger on each button. Or there is the
box layout which can resemble a layout similar to what you would see on the face buttons of a gamepad.
For the example we will see below we will be using the Line layout which will be displayed in both the example below
and the following video. 

    Line Layout              Box Layout

    [B] [C] [D]      or       [A] [C]

 [A]                          [B] [D]

I would like to note that each button is an action that the player can make with the press of a button
if the notation list that the player must press "C" then the player will do just that, but where it gets interesting
is that the same button can have a different result if combined with the motions of the stick listed above.
If the notation asks for "2C" the player will move their aracde stick down and press the C button that would be consider a unique attack
or if the notation asks the player to do a Quarter Circle Forward while pressing the "B" button then the notation will look like this, "236B".
One final note to add is that there will times where the player will be airborne while performing an action that is when the notation will have "j"
which stands for "jumping" so if the notation states "j.B" then while airborne from a jump the player will press B to perform the action in the air.
